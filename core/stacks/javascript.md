# JavaScript / TypeScript / Vue

## Vue

### Vue · 在列表项里放按钮导致 HTML 非法
- **症状**：点行内按钮**触发了整行跳转**；控制台报 DOM 嵌套警告
  （`<a>` 不能嵌套交互元素）
- **原因**：整行是 `<router-link>`（渲染成 `<a>`），按钮放在它里面 → `<a><button></button></a>`
- **修法**：把按钮放到链接**外面**，外层容器改 flex 布局，链接 `flex-grow-1` 占左侧，
  按钮作为**兄弟节点**放右侧
- **来源**：二次元博客（2026-04，关注列表加按钮）→ 已升级为 **R-005**

### Vue · v-if 与 v-else 之间插入其他节点
- **症状**：条件渲染不生效，或者两个分支同时显示 / 都不显示
- **原因**：`v-if` 与 `v-else` 之间**不能有其他元素**（包括注释在某些情况下）
- **修法**：让它们相邻；需要多个节点就用 `<template v-else>`
- **来源**：二次元博客（历史踩坑）

### Vue · 列表 key 用了可变值
- **症状**：列表更新后出现**错位渲染**、输入框内容串行、组件状态错乱
- **原因**：`:key` 用了昵称/索引等会变的值，Vue 复用组件时对不上
- **修法**：`:key` 用**不可变 ID**
- **来源**：通用经验

### Vue · 展示名与标识混用导致功能失效
- **症状**：**本人主页看不到"编辑资料"按钮**；或者跳转到别人主页；
  或者按名字查询查不到
- **原因**：拿**可变的展示名**（昵称）当标识用（路由参数、查询条件、身份判断）
- **修法**：**展示用展示名，路由/查询/身份判断用不可变 ID**
- **来源**：二次元博客（2026-04，主页 URL 改造）→ 已升级为 **R-004**

### Vue · 组件里直接改 store 状态 / 递归更新
- **症状**：`Maximum recursive updates exceeded`，页面卡死
- **原因**：watch → 改状态 → 又触发 watch 的循环
- **修法**：检查 watch 的回调是否修改了它自己依赖的值；用 `watch(..., { flush: 'post' })`
  或加守卫条件（`if (newVal === oldVal) return`）
- **来源**：二次元博客（历史，Profile.vue 视频预览）

## TypeScript

### TS · 类型检查通过但运行时崩
- **症状**：`npm run type-check` 零错误，但页面报 `xxx is undefined`
- **原因**：接口返回的数据类型与手动写的 interface 不一致
  （尤其是**嵌套对象 vs 整数 ID**，见 python.md 的 DRF 那条）
- **修法**：**先看真实响应再写 interface**；对可选字段用 `?.` 和兜底值；
  关键位置加运行时断言而不是只靠类型
- **来源**：二次元博客（2026-04，`'int' object is not subscriptable`）

### TS · 手工构造的对象漏字段
- **症状**：某个页面的功能**看起来"没做"**（如昵称显示失效），但其他页面正常
- **原因**：该处数据是**手工 new 出来的对象**，只挑了几个字段，
  不包含后来新增的字段（如 `display_name`）
- **修法**：grep 所有手工构造响应对象的地方，与接口返回的字段清单核对；
  或直接用接口返回的对象而不是手工拼
- **来源**：二次元博客（2026-04，Friends.vue 搜索结果缺 `display_name`）

## 构建 / 工具链

### Vite · 改了前端代码页面没变
- **症状**：改完 `.vue` 刷新浏览器无变化
- **原因**：dev server 没在跑，或浏览器缓存
- **修法**：确认 `npm run dev` 在运行；`Ctrl+F5` 强刷；
  静态资源加版本号（`?v=N`）做缓存破坏
- **来源**：二次元博客（2026-04，管理后台 CSS 不生效，实为缓存）

### 构建 · 只看 type-check 就以为没问题
- **症状**：`type-check` 通过，但 `build` 失败（或反之）
- **原因**：两者检查的东西不同（类型 vs 打包/依赖解析）
- **修法**：**两者都要跑**，别互相替代
- **来源**：通用经验
