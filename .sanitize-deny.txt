# 脱敏黑名单
#
# 每行一个**正则表达式**，命中任何一条就会拦住提交。
# 以 # 开头是注释，空行忽略。
#
# ⚠️ 这个文件本身是要提交/公开的 ——
#    所以**写"模式"，不要写你真正的敏感值**。
#    例如写 `(?i)password\s*[:=]` 而不是把真实密码贴进来。
#
# 用法：scripts/sanitize-check.ps1（或 .sh）

# ============================================================
# 凭据类 —— 任何项目都必须拦
# ============================================================

# 赋值形式的密码 / 密钥 / token（要求值有一定长度，避免误伤示例占位符）
(?i)(password|passwd|pwd)\s*[:=]\s*["'][^"'\s]{4,}["']
(?i)(secret|token|api[_-]?key|access[_-]?key|private[_-]?key)\s*[:=]\s*["'][^"'\s]{8,}["']

# 中文语境下的凭据表述
# ⚠️ 这一条是实测补上的：只写英文 password 会漏掉「数据库密码: "xxx"」这种写法，
#    而这个项目（以及多数中文项目）恰恰用中文标注
(?i)(密码|口令|密钥|秘钥|令牌)\s*[:：=]\s*["']?[^\s"']{4,}

# 连接串里的明文凭据  scheme://user:pass@host
(?i)[a-z][a-z0-9+.-]*://[^/\s:]+:[^/\s@]+@

# 私钥文件内容
-----BEGIN [A-Z ]*PRIVATE KEY-----

# 常见凭据文件的引用（这种文件不该被提交）
(?i)(mysqlpassword|\.env\.temp|credentials\.json|id_rsa)

# ============================================================
# 本地路径 —— 会暴露用户名、目录结构、项目位置
# ============================================================

# Windows 用户目录（暴露本机用户名）
[A-Za-z]:\\Users\\[^\\\s"'`]+

# 本机开发盘符下的具体项目路径（示例：F:\python2 这种）
[A-Za-z]:\\[A-Za-z0-9_-]*(python|project|code|dev|work)[A-Za-z0-9_-]*\\

# ============================================================
# 个人信息 —— 按需增删
# ============================================================

# 邮箱（示例占位符如 user@example.com 请在下方 allow 区排除）
[a-zA-Z0-9._%+-]+@(qq|163|126|gmail|outlook|hotmail)\.[a-zA-Z]{2,}

# 中国大陆手机号
1[3-9]\d{9}

# 你自己的项目名 / 内部代号 —— 追加在这里
# ============================================================
# （本项目曾用名已脱敏，若以后新增项目请把名字加在这里）

# ============================================================
# 允许清单 —— 命中这些的**不算**问题（先于上面的规则生效）
# ------------------------------------------------------------
# 语法：以 "!" 开头的行表示"如果这一行也匹配，则跳过该命中"
# 用于放过到处都在的示例占位符
# ============================================================
!@example\.com
!your[_-]?(password|token|key)
!<[^>]+>
!\$\{[A-Z_]+\}
!xxx+
!placeholder
# 文档里用来解释规则的示意写法（不是真实连接串）
# ⚠️ 只放过 "user:pass@" 这个**占位形式**；真实的 mysql://root:RealPw@host 不会被放过
!user:pass@
